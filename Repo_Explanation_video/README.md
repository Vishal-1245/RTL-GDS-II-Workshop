## 📚 Repository Overview

This repository documents work completed during the RTL Design Workshop, from foundational RTL design exercises to the physical implementation and analysis of the VSDBabySoC design.

### What's Included?

- **DAY_1–DAY_7:** Workshop exercises, learning materials, and RTL design activities.
- **PD program:** Physical design learning materials and related exercises.
- **VHDL Baby SoC Simulation:** Simulation-related files and results.
- **Post-Route STA and OpenROAD:** VSDBabySoC physical design results, screenshots, and post-route timing analysis reports.
- **Design Visualizations:** Screenshots illustrating floorplanning, clock tree synthesis, placement, and routing.

## 🛠️ Tools and Topics

- RTL design and digital design fundamentals
- VSDBabySoC design flow
- OpenROAD physical design flow
- Static Timing Analysis (STA)
- Simulation and design visualization

## 🎯 Learning Outcomes

- Understand the progression from RTL design to physical implementation.
- Explore the major stages of the RTL-to-GDSII design flow.
- Examine floorplanning, placement, clock tree synthesis, and routing.
- Review post-route static timing analysis results.
- Organize and document design artifacts for technical review.

## 👨‍💻 Purpose

This repository serves as a record of workshop exercises, implementation artifacts, and design results. The accompanying video provides a guided explanation to help reviewers navigate the repository and understand the work presented.
